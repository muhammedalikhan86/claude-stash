# Muhammed Ali Khan owns the whole OFA automation initiative

Muhammed Ali Khan owns the entire OFA (Ongoing Fee Arrangements) automation initiative at
Shaw & Partners — every plugin in it, not just the one being actively worked on. That includes
the OFA tool itself, the Advisor Dashboard, and the Compliance tool.

When writing anything about this initiative — an executive brief, a status update, a proposal,
a governed document — **never describe a component as unowned, unstaffed, or "needing an owner",
and never raise finding an owner as an ask of anyone else.** Muhammed corrected this directly
after an executive brief listed the Compliance tool as "scoped and handed over, not yet started —
needs an owner". That framing is wrong twice over: it is already owned, and putting an
ownership gap in front of executives invites them to solve a problem that does not exist.

A component that has not started yet is described by *when it starts*, not by *who is missing*.
Where the start date depends on another component, tie it to that component's milestone rather
than leaving it open-ended. In this initiative specifically, the Compliance tool is committed and
is aligned with release 2 of the Advisor Dashboard.
